## About Bizerte Tcodi

**Bizerte Tcodi** is a student-run problem-solving hackathon held in Bizerte, Tunisia. It brings together four IEEE student branches from across the Bizerte region — ISET Bizerte, ENIB, ISSATM, and FSB — united under the IEEE Tunisia Section to turn student ambition into real solutions, one hackathon at a time.

- 🌍 **Regional Collaboration**: Entries from multiple IEEE student branches foster friendly competition and technical excellence.
- 💡 **Problem-Solving Focus**: Teams build innovative tech solutions from scratch in a 24–48 hour format.
- 🤝 **Community Building**: Empower participants to become ambassadors for their field and build bridges between future engineers.

---

## Creative Features

- **Animated Hero Section**: Countdown to event date, looping video background, and floating particles.
- **Mono Chrome Theming**: Clean black/white/grey aesthetic with SF Pro and Avatar Airbender fonts.
- **Apple-style Components**: Bento Grid (Magic UI), Timeline (Aceternity), Accordion (Origin UI), Logo Cloud, Footer, and Team Section.
- **WebGL Particles**: Custom WebGL/GLSL shaders render interactive, animated particles.
- **Responsive Design**: Mobile-first, fully responsive across all devices.

## Quick Start

```sh
# 1. Clone the repo
git clone https://github.com/your-username/bizerte-tcodi.git
cd bizerte-tcodi

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev

# 4. Open in your browser
# Visit: http://localhost:3000
```

## Project Structure

- `app/` – Main Next.js app, layout, and global styles
- `components/` – All UI components (hero, carousels, team, footer, etc.)
- `components/ui/` – shadcn/ui primitives + Magic UI, Aceternity, Origin UI components
- `public/` – Static assets (images, fonts, videos)
- `constants/` – Data for partners, navigation, etc.
- `lib/` – Utility functions
