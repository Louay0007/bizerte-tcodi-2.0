## A. Boring Additions (Easy version)

Maintain an array under point increments and return the `k`-th largest **distinct** current value.

### Input

- First line: `n q`, where `1 ≤ n ≤ 2·10^5` and `1 ≤ q ≤ 10^6`.
- Second line: `a1 a2 ... an`, where `1 ≤ ai ≤ 10^9`.
- Next `q` lines, each one of:
  - `1 x`, where `1 ≤ x ≤ n`: increment `ax` by `1`.
  - `2 k`, where `1 ≤ k ≤` the current number of distinct values: query the `k`-th largest distinct value.

### Output

For every type-2 operation, print one integer on its own line.

### Example

```text
Input:
6 7
3 5 9 10 1 1
2 3
1 2
1 4
2 2
1 3
1 3
2 3
Output:
5
9
3
```

### Type/semantic details

- Indices are 1-based.
- Repeated values count once in rank queries.
- Values can grow by at most `q`; 64-bit integer storage is safe and conventional.

## B. Boring Additions (Hard version)

The operations and output are identical to A, but the limits and query guarantee differ.

### Input

- First line: `n q`, where `1 ≤ n ≤ 2·10^5` and `1 ≤ q ≤ 5·10^6`.
- Second line: `a1 a2 ... an`, where `1 ≤ ai ≤ 5·10^6`.
- Next `q` lines:
  - `1 x`, where `1 ≤ x ≤ n`: increment `ax` by `1`.
  - `2 k`, where `1 ≤ k ≤ min(10, current distinct-value count)`: query the `k`-th largest distinct value.

### Output

For every type-2 operation, print one integer on its own line.

### Example

```text
Input:
6 7
3 5 9 10 1 1
2 3
1 2
1 4
2 2
1 3
1 3
2 3
Output:
5
9
3
```

### Type/semantic details

- The small queried rank (`k ≤ 10`) is the defining hard-version guarantee.
- Up to five million operations makes input/output throughput part of the intended difficulty.

## D. Matrices, matrices everywhere

Find the largest side length `k` for which some contiguous `k × k` subsquare has a GCD of at least `x`.

### Input

- First line: `n x`, where `1 ≤ n ≤ 1000` and `1 ≤ x ≤ 10^9`.
- Next `n` lines: `n` integers per line, with `1 ≤ ai,j ≤ 10^9`.

### Output

- One integer: the maximum valid side length `k`.

### Formal condition

For a top-left corner `(r,c)`, with `1 ≤ r,c ≤ n-k+1`, the square is valid when

`gcd({ai,j | r ≤ i ≤ r+k-1, c ≤ j ≤ c+k-1}) ≥ x`.

### Example

```text
Input:
3 3
1 6 3
12 12 12
9 4 15
Output:
2
```

### Type/semantic details

- Matrix coordinates in the mathematical definition are 1-based.
- The statement does not specify the output when every matrix element is below `x`, in which case no valid `k` in `1...n` exists. The natural completion is output `0`, but this must be confirmed before publication.

## E. Matrices are sliding now

The prose asks for maxima of submatrices, but its indexing formula, output count, and sample contradict each other. This problem is not implementable unambiguously as printed.

### Printed input

- First line: `n k`, where `1 ≤ k ≤ n ≤ 3000`.
- Next `n` lines: `n` integers, where `1 ≤ A[i][j] ≤ 10^9`.

### Printed output rule

For every integer `x` from `0` to `n²-1`, define:

- `i = floor(x/k)`
- `j = x mod k`

If `i < n` and `j < n`, print

`max({A[p][q] | i ≤ p < min(i+k,n), j ≤ q < min(j+k,n)})`.

The use of `min` means boundary windows are clipped and can be smaller than `k × k`, despite the statement calling them `k × k` submatrices.

### Printed example

```text
Input:
3 3
1 6 3
12 12 12
9 4 15
Output:
15
```

### Blocking specification conflict

- With `n=3`, `k=3`, and `x=0...8`, the printed formula generates nine valid `(i,j)` pairs and therefore nine outputs, not one.
- The single sample output `15` matches the only full `3 × 3` window.
- The likely intended task is to output maxima for all full `k × k` submatrices, giving `(n-k+1)²` answers, but the statement must be corrected before use.

## F. Bad Habit

Determine whether any contiguous segment of at least `k` days contains at least twice as many non-smoking days (`0`) as smoking days (`1`).

### Input

- First line: `n k`, where `2 ≤ n ≤ 10^5` and `2 ≤ k ≤ n`.
- Second line: `n` binary integers `a1...an`.
- The statement guarantees that the array contains at least one `0` and at least one `1`.

### Output

- Print `YES` if a qualifying segment exists; otherwise print `NO`.

### Exact condition

For some contiguous segment of length at least `k`:

`count(0) ≥ 2 × count(1)`.

### Example

```text
Input:
5 2
0 1 0 0 0
Output:
YES
```

## G. Xor Happiness

For each player `i`, scan players `j > i` from left to right. Start with current power `ai`. Skip `aj` when `aj ≥ currentPower`; otherwise set `currentPower = aj`. The player's happiness is the XOR of the initial power and every lower power adopted during the scan. Print the XOR of all players' happiness values.

### Input

- First line: `n`, where `1 ≤ n ≤ 2·10^5`.
- Second line: `a1...an`, where `1 ≤ ai ≤ 10^9`.

### Output

- One integer: the game's total XOR happiness.

### Examples

```text
Input:
4
3 4 2 1
Output:
5

Input:
8
3 2 7 4 9 1 2 9
Output:
6
```

### Type/semantic details

- Equal powers are skipped because the update condition is strictly lower (`aj < currentPower`).
- Every player's initial power is included, including the last player's.

## H. Night Baron Party

Given a weighted tree, a start node is chosen uniformly among its `n` nodes. For each start, the Night Baron uses the minimum-cost walk that visits every node at least once and may finish at any node. Print the expected cost multiplied by `n`, equivalently the sum of the minimum costs over all start nodes.

### Input

- First line: `n`, where `2 ≤ n ≤ 2·10^5`.
- Next `n-1` lines: `u v w`, describing an undirected edge, with `1 ≤ u,v ≤ 10^6` and `1 ≤ w ≤ 10^8`.

### Output

- One integer: `n × expected minimum traversal cost`.

### Example

```text
Input:
3
1 2 5
1 3 3
Output:
27
```

### Type/semantic details

- Node labels are not bounded by `n`; they are only bounded by `10^6`.
- The sample fixes the intended ending rule: the walk does not need to return to its start.
- If `W` is the sum of all edge weights and `ecc(s)` is the farthest-node distance from start `s`, the per-start minimum is `2W - ecc(s)`. The requested value is `Σs(2W - ecc(s))`.
- Use signed 64-bit integers for weighted sums and the final answer.

## I. Akrem and his rounding habit

The `k`-rounding of `n` is the smallest positive multiple of `n` ending in at least `k` decimal zeros.

### Input

- One line: `n k`, where `1 ≤ n ≤ 10^9` and `0 ≤ k ≤ 8`.

### Output

- One integer: the `k`-rounding of `n`.

### Equivalent definition

The answer is `lcm(n, 10^k)`.

### Examples

```text
Input:
375 4
Output:
30000

Input:
10000 1
Output:
10000

Input:
38101 0
Output:
38101

Input:
123456789 8
Output:
12345678900000000
```

### Type/semantic details

- `k=0` requires zero trailing zeros, so every positive integer qualifies and the answer is `n`.
- The result can reach approximately `10^17`; use a 64-bit integer.

## J. Bohmid and his cumulative sequence

Determine whether `b` occurs in the infinite arithmetic sequence `a, a+c, a+2c, ...`.

### Input

- One line: `a b c`, where `-10^9 ≤ a,b,c ≤ 10^9`.

### Output

- Print `YES` if `b = a + t·c` for some integer `t ≥ 0`; otherwise print `NO`.

### Examples

```text
Input:
1 7 3
Output:
YES

Input:
10 10 0
Output:
YES

Input:
1 -4 5
Output:
NO

Input:
0 60 50
Output:
NO
```

### Type/semantic details

- The sequence index is positive, but the step multiplier is `t=i-1`, so `t` starts at zero.
- When `c=0`, only `b=a` is present.
- For `c≠0`, divisibility alone is insufficient: `(b-a)/c` must also be non-negative.

## K. Akrem’s Scientific Nostalgia

Count sample positions whose DNA string has at least one other input sample at Hamming distance exactly one.

### Input

- First line: `n m`, where `1 ≤ n ≤ 2·10^4` and `1 ≤ m ≤ 20`.
- Next `n` lines: one length-`m` string over `{A,C,G,T}`.

### Output

- One integer: the number of mutated samples.

### Example

```text
Input:
3 3
AAA
AAT
TTT
Output:
2
```

### Type/semantic details

- “Exactly one character” means Hamming distance exactly `1`; insertion and deletion are impossible because every string has the same length.
- Identical duplicate strings have distance `0` from one another and do not make each other mutated.
- The output counts input samples/positions, not unique string values. If a duplicated value has a one-character neighbor, every occurrence of that value satisfies the definition.

## L. The Bizerte Trio

For every `a`, count non-negative integers `x` satisfying `x + (a XOR x) = a`.

### Input

- First line: `t`, where `1 ≤ t ≤ 1000`.
- Next `t` lines: one integer `a`, where `0 ≤ a < 2^30`.

### Output

- For each test case, print the number of valid `x` on its own line, preserving input order.

### Equivalent condition

Every set bit of `x` must be a set bit of `a`. Therefore the answer is:

`2^popcount(a)`.

### Example

```text
Input:
3
0
2
1073741823
Output:
1
2
1073741824
```

### Type/semantic details

- `x=0` is valid for every `a`.
- The largest answer is `2^30 = 1,073,741,824`.

## M. Ahmed and the Magical Stick

Replace at most one array element with any positive integer so that the total product is divisible by `27`, while minimizing the maximum final array element.

### Input

- First line: `n`, where `1 ≤ n ≤ 2·10^5`.
- Second line: `a1...an`, where `1 ≤ ai ≤ 10^9`.

### Operation

- Choose one index `i` and one integer `x ≥ 1`, then assign `ai = x`.
- The stick may be used at most once, so leaving the array unchanged is allowed.

### Output

- One integer: the minimum achievable maximum element.

### Example

```text
Input:
3
2 9 4
Output:
9
```

### Type/semantic details

- Divisibility by `27` depends only on the total exponent of prime factor `3` in the product.
- If replacing index `i`, let `S` be the total exponent of `3` in the original product and let `vi` be the exponent in `ai`. The smallest useful replacement is `3^max(0, 3-(S-vi))`, one of `1, 3, 9, 27`.
- The candidate maximum is the maximum of that replacement and all non-replaced elements.
- The guarantee that a valid choice always exists is redundant because replacing any element with a suitable multiple of `27` always works.

## N. Cybersecurity Agent

Redistribute file size between distinct files so every final size meets its required minimum. Minimize the number of indices whose final size differs from its original size.

### Input

- First line: `n`, where `1 ≤ n ≤ 2·10^5`.
- Second line: current sizes `a1...an`, where `1 ≤ ai ≤ 10^9`.
- Third line: required minimum sizes `b1...bn`, where `1 ≤ bi ≤ 10^9`.

### Output

- One integer: the minimum number of changed files, or `-1` if securing all files is impossible.

### Example

```text
Input:
3
5 2 6
3 4 6
Output:
2
```

### Type/semantic details

- Total size is conserved, so feasibility requires `Σai ≥ Σbi`.
- Every deficit index (`ai < bi`) must change.
- Let total deficit be `D = Σ max(0, bi-ai)`. Among surplus indices (`ai > bi`), choose the fewest whose combined available surplus `ai-bi` reaches `D`; this is achieved by taking surpluses in descending order.
- The answer is `numberOfDeficitIndices + numberOfChosenSurplusIndices`.
- Use 64-bit integers for all sums.

## Publication issues found

1. **Problem E is internally contradictory.** Its printed formula produces a different number of answers from its sample. This requires a statement correction, not merely a grammar edit.
2. **Problem D omits the no-solution result.** If no `1 × 1` square has value at least `x`, the required output is undefined.
3. **Problem E calls clipped boundary regions `k × k` submatrices.** They are smaller than `k × k` whenever `i+k>n` or `j+k>n`.
4. **Problem H uses node labels up to `10^6` while there are only `n ≤ 2·10^5` nodes.** This is valid only if arbitrary labels are intentional; otherwise the bound should be `1 ≤ u,v ≤ n`.
5. **Problem H's endpoint rule is implicit.** The sample confirms that the traversal may end anywhere; state this explicitly.
6. **Problem M's existence guarantee is unnecessary.** A replacement divisible by `27` always exists.
7. **Example headings are inconsistent.** Most problems use `Example`; G, I, and J use `Examples`; M and N use `Example 1` despite showing only one example.
8. **Grammar and typography need normalization.** Examples include `Note :`, `challenge , otherwise`, `The first line one integer`, spaces before commas/periods, lowercase “baron” after introducing “Night Baron,” and `2.10^5` where the rest of the document uses `2·10^5`.
9. **The PDF contains no scoring rules**, although the website copy currently says scoring rules will appear in it.
